# 匿名样例（anonymized samples）

一组**完全合成**的匿名账单/运输/费率样例，用于演示与回归测试确定性引擎，
两种宿主形态（WorkBuddy 专家、Hermes 插件）共用。

## 匿名口径

- 不含任何真实客户、承运商、线路、车型、单号或金额；实体一律 `CARRIER-A` /
  `ROUTE-A1` / `VAN-4T2` 这类占位名。
- 金额单位为整数「分」，币种 CNY；账期 2026-09。
- `rates.csv` 的 `workspace_id` 列必须与案件工作区一致（测试用 `WS-DEMO`；
  实机默认工作区是 `local`，导入前请把该列改成你的工作区）。

## 场景设计

| 账单行 | 关联运输 | 费率 | 预期 |
| --- | --- | --- | --- |
| AB01 | T-A01（ROUTE-A1） | 200000 分/车次 | 应收=实收，差额 0 |
| AB02 | T-A02（ROUTE-A2） | 240000 分/车次 | 多收 20000 分（正向差异） |
| AB03 | （无 trip_ref） | — | 待人工关联，不进差额 |

`expected-summary.json` 由引擎实跑生成（非手写），是本样例的回归金标；
改动引擎后若摘要变化，先确认是预期行为再更新金标。
